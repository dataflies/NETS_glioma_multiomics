# NETS_glioma_multiomics
This repository hosts all R and Jupyter scripts used in our public project for analyzing NETS 
(neutrophil extracellular traps) features in gliomas. It includes data processing and analysis for 
bulk RNA-seq (CGGA_325, CGGA_693, TCGA_LGG/GBM), single-cell RNA-seq, MRI imaging, and spatial 
transcriptomics (GSE237183). Imaging preprocessing and correlation/prognostic analyses of model 
predictions are also included. The deep learning radiomics models and their associated scripts are 
maintained separately at https://github.com/Husky84/MRI-NETs.
